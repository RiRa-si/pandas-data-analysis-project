# Pandas Employee Analysis

A beginner-friendly **Pandas mini project** focused on analyzing employee data using Python, Pandas, and NumPy.

This project was created as part of my Data Science learning journey to practice data manipulation, filtering, cleaning, aggregation, merging, and basic analytical reporting.

## Project Overview

The project uses employee and department data to perform a series of analytical tasks, progressing from basic DataFrame operations to a complete department-level analysis.

The assignment contains **26 practice questions** covering core Pandas concepts.

## Topics Covered

* DataFrame creation and selection
* Column selection
* Conditional filtering
* `.isin()`
* `.between()`
* Creating and modifying columns
* `np.where()`
* String operations
* Sorting
* Missing-value handling
* Duplicate detection
* `GroupBy`
* Multiple aggregations
* Named aggregation
* DataFrame merging
* SQL JOIN concepts using Pandas
* Basic data analysis workflows

## Tools & Libraries

## Key Skills Practiced

### Data Manipulation

Used Pandas to select, filter, modify, and sort employee records.

### Data Cleaning

Practiced identifying missing values, handling missing ages using the median, and checking for duplicate records.

### Aggregation

Used `groupby()` and multiple aggregations to calculate metrics such as:

* Average salary
* Maximum salary
* Minimum salary
* Average experience
* Average performance
* Employee count

### Data Integration

Used `pd.merge()` to combine employee and department information, similar to SQL JOIN operations.

### Analytical Reporting

Created a final department-level report containing employee counts, salary statistics, experience, and performance metrics.
